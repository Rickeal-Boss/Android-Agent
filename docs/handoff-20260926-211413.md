关键决策与依据（详见各 commit message 与 memory）：

- **升级动因**：MiniCPM5-2B 官方 README 明示 requires litert-lm ≥ 0.16（thought channel /
  minicpm5 模型类型 / ThinkingConfig），0.11.0 大概率无法加载。桥接面仅 11 个符号，
  逐一对 v0.17.1 tag 源码核验兼容后才升级（SamplerConfig 逐字段相同；
  ConversationConfig.systemInstruction String?→Contents? 但调用点传 null）。
  源码快照：`_research/models/litertlm171_*.kt`（Config/Engine/Conversation/Message/Capabilities）。
- **重大解锁**：0.17.1 开放 RepetitionPenaltyConfig / NoRepeatNgramConfig / ThinkingConfig /
  maxOutputToken —— Wave 19「SamplerConfig 无 repeat penalty、升级零收益」的调研结论自此
  **失效**，胡言乱语/死循环有了根治手段。当前 repPenalty 走 SamplingParams.repetitionPenalty
  既有字段（UI 已有滑条 1..2，之前是死值），按模型下限由档案生效（如 Qwen2.5 官方 1.1）。
- **按模型采样档案**（ModelSamplingProfiles.kt，含完整 evidence）：数值全部官方一手——
  Qwen2.5 0.7/0.8/20/repPen1.1（官方 gen_config）；R1 蒸馏 temp 0.5–0.7（官方令防贪心循环，
  agent 覆写 0.4 自动抬回 0.5）；MiniCPM5 temp1.0/topP0.95 + maxTokens≥2048（思考截断就无答案）
  + ctx 封顶 4096（litertlm 元数据 max_num_tokens，原生 131k 与端侧无关）；SmolVLM2 下限 0.3
  （README：贪心 repetitive/verbose）；Gemma4 系口径 1.0/0.95/64 + ctx 8192（内存按 KV@4096 预算）。
  生效点唯一（AgentRunner 组装 config 后），文件名精确匹配（同 ModelGpuSupport 约定），
  UI 保存值不被改写（运行时围栏），变更打 AgentLogStore.info。
- **缩略图根因**：importAttachment 落库的 `Attachment.Image.uri` 是裸绝对路径
  （`/data/user/0/...`），旧 decodeThumbnail 只走 ContentResolver → 无 scheme Uri 直接
  FileNotFoundException → 气泡永远显示占位图标（用户截图实证）。GlassImageThumb 支持三态
  （裸路径/file://，IO 解码 + RGB_565 + inSampleSize，不引 Coil）。
- **MiniCPM5-2B**：下载地址 Wave 18 已在预设（`litert-community/MiniCPM5-2B_int4.litertlm`
  1.55GB，hf-mirror + ModelScope 双镜像 2026-09-26 复核实存）；本轮补齐模型族/采样档案/
  GPU 白名单（README 有 Galaxy S26 OpenCL 全委托实测「zero rejected ops」+ 0.17.1 满足 ≥0.16）。
- **CI 终态**：a39088a Build/Release success；artifacts：release 69.8MB（0.17.1 native 库增量，
  旧 59.8MB）/ mapping 4.1MB / debug 39.1MB，均未过期。
- VL 系（SmolVLM2/Qwen2-VL/LFM2.5-VL/MiniCPM-V-4）：0.17.1 版本前提已达标，但「视觉后端 GPU +
  解码」组合真机未实测 → **GPU 白名单保持关闭**，预设文案已同步。
